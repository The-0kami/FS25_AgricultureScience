# Kompatibilität und Abhängigkeiten

| Komponente | Status |
|---|---|
| Farming Simulator 25 | Zuletzt dokumentierter SP-Teststand 1.25.0.0 |
| AutoDrive | Für automatisierte Fahrten erforderlich; Referenzversion 3.0.1.4; nicht enthalten |
| APS + SmartGate | Beide für A.S.S.-Serviceabläufe erforderlich |
| Courseplay | Optionale Integration; nicht alle Modi aktuell abgenommen |
| Servicegebäude | Nur tatsächlich unterstützte und korrekt verknüpfte native Einrichtungen |

Basic APS-Parken und SmartGate-Torsteuerung können jeweils unabhängig verwendet werden. Die Kombination von Servicefunktion, Bay, Farmrechten und AD-Route muss im konkreten Spielstand gültig sein.

**Multiplayer:** Identische ZIP-Inhalte auf Server und Clients sind nötig. Abschließende Dedi- und parallele Multiplayer-Tests stehen noch aus.
