# Installation

**Hinweis:** Dieses Repository dient derzeit der Vorbereitung. Es ist noch kein freigegebenes Paket-Release hier veröffentlicht.

Sobald das Paket verfügbar ist:

1. Farming Simulator 25 bzw. Dedicated Server beenden und Spielstand/Mod-Verzeichnis sichern.
2. Das äußere `Agriculture_Science_Pack_1.0.zip` entpacken.
3. Die enthaltenen `FS25_APS_AgricultureScience.zip` und `FS25_SmartGate_AgricultureScience.zip` in das Mods-Verzeichnis kopieren.
4. **Diese beiden Mod-ZIPs nicht weiter entpacken.**
5. Alte parallele Versionen oder gleichnamige entpackte Modordner entfernen.
6. AutoDrive in einer geeigneten Version separat installieren und benötigte Mods im Spielstand aktivieren.
7. Im Agriculture-Science-Menü Park- und Serviceoptionen konfigurieren. Service-Bays brauchen passende native Servicequellen und ein verwendbares AutoDrive-Ziel.

## Dedicated Server

Server und Clients benötigen **bytegleiche Mod-ZIPs** sowie kompatible externe Abhängigkeiten. Vorher Server und Spielstand sichern. Die vollständige Dedi-Abnahme der Preview steht noch aus.

## Sicherheit

Original-Downloadquellen und Prüfsummen werden mit dem jeweiligen Release dokumentiert. Keine nicht geprüften Entwicklungsbuilds mit Release-Dateien mischen.
